# 🌍 EduQuest — Gamified Environmental Learning

EduQuest is an interactive **environmental education platform** that makes learning about sustainability fun through **games, quizzes, and AI-powered assistance**. The platform combines **retro-inspired design with modern technology** to create an engaging experience for learners of all ages.

---

## 🎮 Features

### 🌱 Gamified Learning
- Educational **mini-games built using Godot Engine**
- Learn environmental concepts through **interactive gameplay**
- Topics include:
  - Climate change
  - Renewable energy
  - Biodiversity
  - Waste management
  - Sustainable living etc.

### 🧠 Knowledge Check
- Built-in **quizzes after gameplay**
- Reinforce concepts learned in the games
- Instant feedback and scoring

### 🤖 AI Learning Assistant
- Integrated **AI assistant for guidance**
- Helps users:
  - Understand environmental concepts
  - Get hints during quizzes
  - Clarify doubts
  - Explore sustainability topics

### 🕹 Retro UI Experience
- **Retro-inspired pixel aesthetic**
- Nostalgic **arcade-style interface**
- Smooth UI built with modern frontend tools

### 📊 Learning Progress
- Track quiz scores
- Monitor improvement
- Encourage continuous learning
